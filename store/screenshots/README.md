# Screenshots to capture

The store needs at least 1 (up to 5) screenshots at **1280×800** (or 640×400), PNG or JPEG, full-bleed. I can't capture these without the extension loaded in a real Chrome, so grab them yourself.

Tips: use a clean Chrome profile, a 1280×800 window (DevTools device toolbar, or `Cmd+Shift+4` then crop), a neutral wallpaper, and a video you have rights to show (or a Creative Commons one). Don't show the YouTube logo prominently or other people's private info.

1. **Hero:** a code editor or doc filling the screen, with the Porthole window floating in a corner playing video. Caption overlay: "Keep watching while you work".
2. **The button:** the YouTube player with the Porthole button highlighted in the control bar.
3. **The controls:** the floating window with controls visible (seek bar, play, next, speed).
4. **Two monitors / drag anywhere:** window dragged beside another app.
5. **Settings:** the options page.

Save finals here as `1-hero.png` etc. and upload in the dashboard.
